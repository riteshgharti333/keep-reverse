# Little Notes

A lightweight, local-first notes app built with React and Vite.

## Run it

Requires Node.js 20.19+ or 22.12+.

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Features

- Quick text notes and checklists
- Search across note titles, text, checklist items, and labels
- Labels, color choices, and pinning
- Reminders
- Archive, trash, restore, and permanent deletion
- Responsive layout with local browser storage

Notes are stored in the browser's `localStorage` on this device. This starter
does not include accounts, cloud sync, collaboration, or server-side storage.
